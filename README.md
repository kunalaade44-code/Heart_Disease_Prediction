# Heart Disease Prediction
A model will created using Supervise Learning Algorithm.


## 🚀 How to Run the Application Locally

Follow these step-by-step instructions to get the application up and running on your local machine.

### Prerequisites
Make sure you have **Python 3.8+** and **Git** installed on your computer.

### 1. Clone the Repository
Open your terminal or command prompt and run the following commands:
```bash
https://github.com/kunalaade44-code/Heart_Disease_Prediction.git
```

### 2. Install Dependencies
Install all the required machine learning and web framework packages:
```bash
pip install streamlit
pip install joblib
```

### 3. Launch the App
Run the application using the appropriate command for your web framework:
  ```bash
  streamlit run app.py
  ```


After running the command, open your web browser and navigate to the local URL displayed in your terminal (e.g., `http://localhost:8501` or `http://127.0.0.1:5000`).
